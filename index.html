인터넷 없이도 사용할 수 있나요?

공개 사이트에 처음 접속할 때는 인터넷이 필요합니다. 앱 전체를 내려받아 로컬에서 실행하면 화면, 검토 규칙, 합성 예시와 저장한 사건은 인터넷 없이 사용할 수 있습니다. KIPRIS Plus 조회와 외부 AI 분석에는 인터넷이 필요하며, 내부망 모델은 해당 망에 연결되어 있어야 합니다.

브라우저에서 API 연결이 막히면 어떻게 하나요?

GitHub Pages는 화면과 파일을 제공하며 API 중계 서버를 실행하지 않습니다. 공개 사이트의 API 직접 연결에는 제공자의 브라우저 연결(CORS) 허용이 필요합니다. 연결이 차단되면 앱 전체를 내려받고 README에 따라 로컬 실행 도우미를 실행해 주세요. 파일 추가, 예시 보기와 기본 예비 점검은 API 연결 없이 사용할 수 있습니다.

긴 문서와 많은 규칙은 어떻게 처리하나요?

한 번의 요청 예산은 기본 128,000 토큰입니다. 문서와 규칙을 나누어 검토하고, 원문 식별자와 근거를 유지한 채 단계별 결과를 정리합니다. 출력이 잘리거나 자료가 누락되면 검토를 완료한 것으로 표시하지 않습니다.

PDF는 어떻게 읽나요?

내장 JavaScript 파서로 텍스트를 먼저 읽습니다. 스캔본·표·수식·복잡한 글꼴은 자동 판독이 제한될 수 있어요. 원문 텍스트를 보완하거나, PDF 입력을 지원하는 Responses 모델에 연결해 읽을 수 있습니다. 원문의 쪽수와 인용 문구를 확인하기 전에는 완전한 자료로 간주하지 않습니다.

검토 내역은 자동으로 저장되나요?

API 키와 작업 자료는 현재 탭에서 다룹니다. 탭을 닫기 전에 ‘사건 저장’으로 내역을 내려받으세요. 보고서에는 검토 범위, 발견 사항과 미확인 항목을 기록하며 API 키를 포함하지 않습니다.
